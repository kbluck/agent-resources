This is a repository containing useful agent skill and sub-agent definitions that can be imported into any project using a CLI such as `npx skills` or `bunx skills`.

Use the `skill-creator` skill to create new skills, modify and improve existing skills, and measure skill performance.

Use the [agent-skills](https://agentskills.io/mcp) MCP server for additional guidance on the best practices for creating, improving, and measuring agent skills.
