# British and American Spelling Rules

Spelling differences between British English (BrE) and American English (AmE) follow regular patterns. Most come from Noah Webster's
spelling reforms of the early nineteenth century, which brought American spelling closer to pronunciation and dropped silent
letters. Each section below gives one pattern, its word list, and the words both varieties spell alike, which are the ones most
often "corrected" by mistake.

## Colour and Color

British English keeps the `-our` ending it took from French; American English drops the `u`.

| BrE | AmE |
| :-- | :-- |
| armour | armor |
| behaviour | behavior |
| colour | color |
| favour, favourite | favor, favorite |
| flavour | flavor |
| harbour | harbor |
| honour | honor |
| humour | humor |
| labour | labor |
| neighbour | neighbor |
| rumour | rumor |
| saviour | savior |
| vapour | vapor |

British English keeps the `u` before `-able`, `-al`, `-ed`, `-er`, `-ful`, `-ing`, `-ite`, and `-less` (`honourable`, `behavioural`,
`colourful`, `favourite`, `humourless`). It drops the `u` before `-ary`, `-ation`, `-ific`, `-ize` or `-ise`, and `-ous`, so these
are spelled alike in both varieties:

| Both |
| :--- |
| honorary |
| humorous, laborious, vigorous, glamorous |
| coloration (BrE also colouration) |
| vaporise or vaporize, according to the `-ise` rule |

Agent nouns and Latin words end in `-or` in both varieties: `actor`, `author`, `doctor`, `editor`, `error`, `horror`, `mirror`,
`terror`. `Glamour` keeps its `u` in both.

## Centre and Center

Many words borrowed from French end in `-re` in British English and `-er` in American English.

| BrE | AmE |
| :-- | :-- |
| calibre | caliber |
| centre | center |
| fibre | fiber |
| litre | liter |
| lustre | luster |
| metre (unit) | meter |
| sombre | somber |
| spectre | specter |
| theatre | theater |

Exceptions:

- Both varieties use `meter` for a measuring device: `thermometer`, `voltmeter`, `parking meter`.
- After `c` or `g`, American English keeps `-re` to keep the consonant hard: `acre`, `massacre`, `mediocre`, `ogre`.
- American proper names sometimes keep `-re`, especially venues named Theatre.

## Organise and Organize

British English accepts both `-ise` and `-ize` for most of these verbs and their derived nouns. `-ise` is more common in everyday
British use; `-ize` is the house style of Oxford University Press and some international organizations, known as Oxford spelling.
American English uses `-ize`.

| BrE | BrE (Oxford spelling) | AmE |
| :-- | :-------------------- | :-- |
| apologise | apologize | apologize |
| authorise, authorisation | authorize, authorization | authorize, authorization |
| customise | customize | customize |
| initialise | initialize | initialize |
| normalise | normalize | normalize |
| optimise | optimize | optimize |
| organise, organisation | organize, organization | organize, organization |
| recognise | recognize | recognize |
| serialise | serialize | serialize |
| synchronise | synchronize | synchronize |

Some verbs are spelled `-ise` in both varieties, because the ending is part of the root rather than the Greek suffix `-ize`:

| Both |
| :--- |
| advertise, advise, chastise, comprise, compromise |
| despise, devise, disguise, enterprise, excise, exercise |
| franchise, improvise, merchandise, premise, revise |
| supervise, surmise, surprise, televise |

A few are spelled `-ize` in both: `capsize`, `prize` (to value), `seize`, `size`.

## Analyse and Analyze

Verbs from Greek `-lysis` end in `-yse` in British English, Oxford spelling included, and `-yze` in American English.

| BrE | AmE |
| :-- | :-- |
| analyse | analyze |
| breathalyse | breathalyze |
| catalyse | catalyze |
| electrolyse | electrolyze |
| hydrolyse | hydrolyze |
| paralyse | paralyze |

## Doubled and Single L

When a suffix that begins with a vowel (`-ed`, `-ing`, `-er`, `-ery`, `-ous`) follows a final `l` after a single vowel, British
English doubles the `l`. American English doubles it only when the last syllable of the root is stressed.

| Root | BrE | AmE |
| :--- | :-- | :-- |
| cancel | cancelled, cancelling | canceled, canceling |
| counsel | counsellor | counselor |
| fuel | fuelled, fuelling | fueled, fueling |
| jewel | jeweller, jewellery | jeweler, jewelry |
| label | labelled, labelling | labeled, labeling |
| marvel | marvellous | marvelous |
| model | modelled, modelling | modeled, modeling |
| quarrel | quarrelled | quarreled |
| signal | signalled, signalling | signaled, signaling |
| travel | travelled, traveller | traveled, traveler |

When the last syllable is stressed, both varieties double the `l`: `compelled`, `controlling`, `patrolling`, `rebellion`.
`Cancelled` and `cancellation` are also common in American writing; `cancellation` is the usual American spelling.

The pattern runs the other way for some roots: British English writes a single `l` where American English writes `ll`.

| BrE | AmE |
| :-- | :-- |
| distil | distill |
| enrol, enrolment | enroll, enrollment |
| enthral | enthrall |
| fulfil, fulfilment | fulfill, fulfillment |
| instil | instill |
| instalment | installment |
| skilful | skillful |
| wilful | willful |

## Catalogue and Catalog

British English keeps the silent `-ue` of these Greek words. American English drops it in a few common words and keeps it in the
rest.

| BrE | AmE |
| :-- | :-- |
| analogue | analog |
| catalogue | catalog |

Both varieties write `dialogue` for a conversation, and both usually write `dialog` for the dialog box of a user interface. Both
write `epilogue`, `monologue`, `prologue`, and `travelogue`. `Analog` is common in British computing too, and `catalogue` and
`analogue` are accepted variants in American English, so prefer the project's existing usage when it is consistent.

## Anaemia and Anemia

British English keeps the `ae` and `oe` of Latin and Greek words, mostly in medicine and science. American English writes a single
`e`.

| BrE | AmE |
| :-- | :-- |
| anaemia | anemia |
| anaesthetic | anesthetic |
| diarrhoea | diarrhea |
| haemorrhage | hemorrhage |
| leukaemia | leukemia |
| manoeuvre | maneuver |
| oesophagus | esophagus |
| oestrogen | estrogen |
| orthopaedic | orthopedic |
| paediatric | pediatric |

`Encyclopedia`, `fetus`, and `medieval` are now usual in British English too. `Archaeology` is usual in American English as well as
British.

## Defence and Defense

A few nouns end in `-ence` in British English and `-ense` in American English. Most `-ence` nouns are the same in both:
`difference`, `presence`, `reference`, `sentence`.

| BrE | AmE |
| :-- | :-- |
| defence | defense |
| licence (noun) | license |
| offence | offense |
| pretence | pretense |

British English spells the verb with an `s` and the noun with a `c`, while American English uses one spelling for both:

| BrE noun | BrE verb | AmE noun and verb |
| :------- | :------- | :---------------- |
| licence | license | license |
| practice | practise | practice |

So a British project has "a software licence" and "licensed under", and "good practice" and "practise the steps". `Advice` and
`advise` differ in both varieties.

## Silent E Before a Suffix

Before a suffix that begins with a vowel (`-able`, `-ing`), British English sometimes keeps a silent final `e` that American English
drops. British English accepts the shorter forms too.

| BrE | AmE |
| :-- | :-- |
| ageing | aging |
| likeable | likable |
| liveable | livable |
| rateable | ratable |
| sizeable | sizable |
| unshakeable | unshakable |

Before `-ment`, British English usually writes `acknowledgement` and `judgement`, and American English `acknowledgment` and
`judgment`. British legal writing uses `judgment` for a court's decision.

## Learnt and Learned

British English uses both forms for some irregular verbs; American English prefers `-ed`. Both are correct British, so treat these
as preferences rather than errors.

| BrE | AmE |
| :-- | :-- |
| burnt or burned | burned |
| dreamt or dreamed | dreamed |
| learnt or learned | learned |
| spelt or spelled | spelled |
| spoilt or spoiled | spoiled |
